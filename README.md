# PlaceReady — Stage 1 UI Scaffold

A responsive, frontend-only student placement preparation PWA project built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the project folder.
2. Open it in Visual Studio Code.
3. Use the **Live Server** extension and choose **Open with Live Server** on `index.html`.
4. Use the sidebar to visit each page. On small screens, use the menu icon.

Opening with Live Server is recommended; later stages will use service workers, which require `localhost` or HTTPS.

## Stage 1 status
- Responsive dashboard layout and navigation across all seven pages.
- Profile form with basic validation and browser LocalStorage saving.
- Responsive styling and mobile navigation.
- Placeholder panels for the modules scheduled in Stage 2.
- Reset PlaceReady browser data control.

## Planned next stages

This is a frontend-only educational project. LocalStorage data remains in the current browser and is not synchronized to other devices.
